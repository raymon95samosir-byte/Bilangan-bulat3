Jenis-jenis Bilangan Bulat

➖

Bilangan Negatif

..., -5, -4, -3, -2, -1

⚪

Nol (0)

Bukan positif maupun negatif.
Titik tengah garis bilangan

➕

Bilangan Positif

1, 2, 3, 4, 5, ...
Berada di kanan nol

OPERASI HITUNG
04 / 08

Penjumlahan & Pengurangan

➕ Penjumlahan

Tanda sama → jumlahkan & ikuti tanda

(+5) + (+3) = +8
(-4) + (-6) = -10
(+7) + (-3) = +4

➖ Pengurangan

a - b = a + (-b)

(+8) - (+3) = +5
(-5) - (+2) = -7
(+4) - (-6) = +10
OPERASI HITUNG
05 / 08

Perkalian & Pembagian

✖️ Perkalian

Tanda sama → positif
Tanda beda → negatif

(+4) × (+3) = +12
(-5) × (-2) = +10
(+6) × (-3) = -18

➗ Pembagian

Aturan tanda sama seperti perkalian

(+12) ÷ (+3) = +4
(-20) ÷ (-4) = +5
(+15) ÷ (-5) = -3
SIFAT-SIFAT
06 / 08

Sifat-sifat Bilangan Bulat

Komutatif

a + b = b + a
a × b = b × a

Asosiatif

(a + b) + c = a + (b + c)
(a × b) × c = a × (b × c)

Distributif

a × (b + c) = (a × b) + (a × c)

Identitas

a + 0 = a
a × 1 = a

LATIHAN
07 / 08

Contoh Soal

Soal 1

Hitung: (-12) + 8 - (-5)

= -12 + 8 + 5 = +1

Soal 2

Hitung: (-6) × 4 ÷ (-3)

= -24 ÷ (-3) = +8
